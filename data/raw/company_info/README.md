# 公司基本信息

建议至少包含：股票代码、公司名称、上市日期、行业、发行价、发行规模、市值区间。

每家公司使用独立子目录，命名为 `股票代码_公司名称/`。目录内只维护一个结构化入口 `公司信息.json`，集中记录公司、发行、文档来源及三个原始数据目录的关联路径。

每个字段需记录来源或计算口径。港交所配发结果等原始公告与结构化公司信息同时保留；计算字段必须附公式，上市前特征必须标注可用日期。

`公司信息.json` 中的 `documents` 登记PDF、Word或文本资料；同一类型存在多个版本时，
使用不同映射键，并为每项填写相同的 `document_type`。额外结构化数据写入
`datasets`。执行 `scripts/register_company_data.py` 后，系统会校验文件哈希并登记到
`data/app.db`；目录中存在但未声明的文件会明确告警。
