# Agent 提示词

本目录只保留当前运行版本，避免旧模板与生效模板混杂。历史差异由发布记录管理；每次运行会
把实际提示词版本、SHA-256 和完整快照写入 `ToolCall`，即使模板以后更新，历史分析仍可审计。

## 当前调用链

1. `discovery/vector_query_planning_v2.md`
   - 从当前文档目录和均匀样本生成公司特异检索问题，不套固定风险清单。
   - 查询集合覆盖直接事实、异常变化、权利义务、依赖关系、反证缓释和跨章节核对。
2. `discovery/document_risk_discovery_v6.md`
   - 使用系统化阅读视角发现文档动态主题，并明确候选成立门槛。
   - 首轮完整返回；仅在确有证据独立遗漏时补扫一次，容量限制不等于风险总量限制。
   - 明确表格单位/期间、严重程度、置信度、反证和不确定性的校准方式。
3. `discovery/risk_consolidation_v3.md`
   - 按主体、底层事实、风险机制、期间状态四项条件执行语义合并。
   - 每个原始候选必须有唯一去向，相关但可独立核验的事项不得强并。
4. `discovery/company_risk_scope_v4.md`
   - 生成公司画像和范围建议；信息不足时保守纳入，不在人工确认前自动删除候选。
5. `search/role_search_planning_v4.md`
   - 为每项风险生成低重复、互补的支持、反证、期间、表格与交叉引用检索问题。
6. `roles/*_v2.md`
   - 财务、法律、业务、市场四套详细专业章程，分别规定核验视角、证据纪律和跨角色边界。
7. `decision/evidence_analysis_v5.md`
   - 同一角色按批次核验全部分派风险，逐项检查主体、期间、数字、条款、反证和证据冲突。
8. `decision/decision_adjudication_v4.md`
   - 对全部有证据专业提案作最终机器复核，校准结论、严重程度、置信度和未决边界。

## 修改规则

- 优先服务赛题的风险抽取准确率、证据召回率和链路可追踪率。
- 不得在提示词中写入测试答案、特定公司结论、上市后行情或真实密钥。
- 修改任何生效模板时同步更新版本号、测试与项目状态说明。
- JSON 字段、证据数量和 ID 白名单必须同时由提示词与代码模型校验，不能只依赖模型自觉。
- 阅读视角用于防止漏检，不得退化为固定主题清单；新公司、新行业和新型交易安排仍应由原文
  动态产生候选。
