# 数据泄漏检查清单

- [x] 按招股书年份进行时间顺序切分，不随机打乱公司样本。
- [x] 所有特征都记录 `available_at` 或等价可用时间。
- [x] 预测时点之后的行情、新闻和真实标签未进入输入。
- [x] 特征标准化和缺失值填充只在训练集拟合；阈值只在验证集选择。
- [x] 同一公司及同一招股书版本不会跨训练、验证和测试集合。
- [ ] 提示词调优未查看测试集真实标签。
- [x] 测试公司自身招股书可在推理时检索，但索引不包含上市后材料。
- [x] 报告展示字段与模型输入字段分离，避免展示层反向污染特征。
- [x] `data/raw/market` 和 `data/processed/competition/market_labels.*` 只用于标签与回测，
  不进入上市前特征快照。
- [x] 发行价代理、上市日推导和异常样本排除规则在查看测试集结果前固定，并在标签行中保留
  来源与排除原因。

说明：市场标签文件仅在构造“此前IPO环境”时按 `observation_date < as_of_date` 使用已经公开
可见的历史样本，当前公司的目标列始终单独保存并禁止进入模型特征。2025时间回放结果已在
开发中查看，不能再作为最终未触碰盲测。
