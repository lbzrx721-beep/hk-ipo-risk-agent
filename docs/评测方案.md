# 评测方案（初稿）

## 抽取

- 字段级准确率与召回率。
- 风险类型准确率。
- 证据页码正确率。
- 证据片段召回率。
- 数值、单位、期间一致率。

## 协同链路

- Agent、工具调用和证据来源可追踪率。
- 冲突发现率与有效裁决率。
- 无证据结论拦截率。

## 风险预测

- 主任务：上市后5个交易日显著下跌风险。
- 辅助任务：1、20、60个交易日风险。
- 当前可复现标签口径：第N个交易日收盘价相对发行价收益率不高于-10%时记为
  “显著下跌”；阈值由 `configs/base.yaml` 的
  `prediction.significant_drop_threshold_pct` 统一配置，不允许在训练集、验证集和测试集
  分别调节。
- 发行价优先使用证券基本信息表的正式上市价格；该表不可用时，允许使用上市首日
  `S_DQ_PRECLOSE` 作为代理，但必须在标签中保留 `offer_price_source`。
- 训练/验证/测试按招股书年份顺序切分：2020—2023年训练、2024年验证、2025年测试。
- 指标：PR-AUC、召回率、Brier Score、校准曲线、Top-K命中率。
- 实验：仅基本面、仅市场、融合模型三组消融。

## 首轮基线结果（2026-07-23）

- 当前“招股书侧”仅包含页数、文件大小、发售描述和日期等结构特征，尚未包含批量Agent
  风险发现结果，因此准确名称为 `prospectus_only`，不把它误称为完整基本面模型。
- 可建模样本554家：训练367、验证73、测试114；五日显著下跌正例分别为89、25、28。
- 融合逻辑回归在2024验证集的PR-AUC为0.3089，低于正例基准率0.3425；Top-20%精确率
  0.2667，同样低于基准率，业务质量门禁未通过。
- 2025时间回放结果已经被开发人员查看，因此它是回测集，不再宣称为未触碰的最终盲测集。
  正式比赛评估需要赛事另行提供的隐藏测试，或重新封存未参与开发的公司批次。
- 当前基线的价值是验证Point-in-Time、时间切分、消融、指标、解释和门禁完整可运行；
  下一实验必须加入批量Agent风险强度、证据质量、角色分歧和风险类别特征。
